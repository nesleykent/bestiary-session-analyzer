About This Site

This site reads a pasted hunting session log and estimates either Bestiary progress or task completion time for the creatures it can match. It is not a save tracker, an official profile mirror, or a source of authoritative in-game progress.

Creature metadata used by the calculator is loaded from the TibiaDraptor Bestiary API and adapted for this app. Creature links shown in the results point to Tibia Fandom. If the upstream data changes, if a creature name in the log does not match cleanly, or if your session text is incomplete, the numbers shown here can be wrong.

The estimate is based on your pasted session only. It assumes the kill rate in that log is a reasonable basis for projecting the remaining kills to the final Bestiary stage. Boosts, prey, rapid respawn, party composition, route changes, interruptions, and other hunting conditions can make the projected time unrealistic.

The code for this project is available on GitHub. Problems and corrections can be submitted through GitHub Issues.
